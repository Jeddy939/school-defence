# Schoolyard Defence

A browser RTS-defense game where exhausted faculty try to hold the staffroom against escalating waves of chaotic students in an exaggerated Australian public school setting.

Version 2 is the current baseline for the playable release.

## Pitch

`Schoolyard Defence` is a fast, funny defense game with light RTS controls:

- build departments and barricades
- harvest grants and curriculum to fund the school
- recruit specialist staff units
- survive increasingly ridiculous student waves

The tone is the hook. The game should feel readable in under 10 seconds and memorable in under 30.

## Controls

- `Left Click`: select units and buildings
- `Right Click`: move, attack, gather, or build
- `Middle Mouse`: pan the camera
- `Mouse Wheel`: zoom
- `C`: recenter the camera on the staffroom

## Demo Flow

For a clean class presentation, trailer clip, or Itch.io capture:

1. Start a new run and show the mission briefing.
2. Select the Teacher's Aide and begin gathering from bookshelves/admin.
3. Place one clean defensive line with lockers.
4. Recruit at least one combat unit before the first wave.
5. Let the first wave collide with the defense so the audience sees the core loop immediately.

## Run Locally

Prerequisite: Node.js

1. Install dependencies:
   `npm install`
2. Start the dev server:
   `npm run dev`
3. Build for production:
   `npm run build`
4. Preview the production build:
   `npm run preview`

## Presentation Notes

This project is strongest when presented as:

- a playable browser build
- a short GIF or trailer showing build, recruit, defend
- a few screenshots that clearly show the Australian school theme
- a one-line pitch above the embed

Recommended headline:

`Protect the staffroom. Balance the budget. Survive the students.`
